Datasets

AVS-QA

A comprehensive multimodal dataset combining audio, video, and sensor data with question-answer pairs for cross-modal understanding research.

SensorCap

LLM-assisted softly-labelled IMU sensor data captioning dataset with feature summarizations and narrations of human activities.

OpenSQA

Open-source sensor-aware question-answering or instruction-tuning dataset covering IMU data interpretations for human activities.

LargeSet: Sound Source Localization

Large-scale dataset for multichannel sound source localization research with diverse acoustic scenarios and precise ground truth localization information.

Aliasing Detection Dataset

A dataset consisting of STFTs derived from the UrbanSound8K Dataset, and ESC50 Dataset which are either aliasing or nonaliasing.

Models

RAVEN: Multimodal Reasoning

State-of-the-art multimodal reasoning model combining audio, video, and sensor data for comprehensive scene understanding and cross-modal reasoning.

LLaSA: Sensor-Language Model

Specialized language model fine-tuned for sensor data interpretation and natural language generation, bridging sensors and human-understandable descriptions.

Usage Guidelines

For Datasets:

  • Cite the relevant publications associated with each dataset
  • Follow the licensing terms specified for each dataset
  • Consider contributing back improvements or extensions to the community

For Models:

  • Check model requirements and compatibility before deployment
  • Follow the model-specific licensing and usage terms
  • Report issues or improvements through our GitHub repositories

For questions about datasets, models, or collaboration opportunities, please reach out to our team.
